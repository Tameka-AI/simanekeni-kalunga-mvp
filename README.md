# Simanekeni Kalunga Interactive Hymn Book — Private MVP

Private demonstration of a digital interactive hymn book for the traditional Catholic Oshiwambo hymnal *Simanekeni Kalunga / Simanekeni Karunga*.

## Features (MVP)

- Single hymn (No. 178 — title hymn "Simanekeni Karunga")
- Line-by-line lyrics with real-time highlight synced to audio
- Play / Pause
- Slow mode (0.5x) for learning
- Built-in timestamp capture tool (press Space while playing to mark line starts)

## Setup

1. Place your audio recording as `public/hymn_178.mp3`
2. `npm install`
3. `npm run dev`
